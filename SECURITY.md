# Politica di Sicurezza

## Versioni Supportate

Vengono fornite patch di sicurezza solo per la versione più recente.

| Versione | Supportata          |
| ------- | ------------------ |
| v1.0.x  | ✅ Sì               |
| < v1.0  | ❌ No               |

## Segnalazione di una Vulnerabilità

Se hai trovato una vulnerabilità di sicurezza in questo progetto, ti preghiamo di **non aprire un'issue pubblica**. Invece, contatta direttamente l'autore tramite LinkedIn:

[Lorenzo Frasconi su LinkedIn](https://www.linkedin.com/in/lorenzo-frasconi/)

Apprezziamo il tuo aiuto nel mantenere questo progetto sicuro per la comunità.
