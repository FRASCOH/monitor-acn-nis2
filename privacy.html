2. Principi Fondamentali & Privacy by Design

NIS2 Cyber Monitor è stata progettata con un rigoroso approccio di Privacy by Design e Data Minimization:

  • Nessun Account Richiesto: L'app può essere utilizzata in tutte le sue funzioni senza registrazione, senza fornitura di credenziali o di email.
  • Nessun Tracciamento Pubblicitario: Non vengono impiegati identificatori di tracciamento (IDFA/GAID), né SDK di advertising, né strumenti di profilazione commerciale.
  • Archiviazione Locale & Keychain: Le preferenze, gli elementi preferiti e le chiavi API vengono memorizzati esclusivamente sul dispositivo locale dell'utente e nel portachiavi protetto hardware Apple Keychain.

3. Tipologia di Dati Trattati e Permessi Dispositivo

Di seguito il dettaglio completo delle tipologie di dati trattati dai servizi integrati nell'app:

A. Notifiche Push (OneSignal SDK)

Per consentire la ricezione in tempo reale degli avvisi relativi a nuove determine, scadenze o decreti, l'app utilizza il servizio OneSignal. L'iscrizione avviene su base puramente facoltativa (Opt-In tramite esplicito consenso dell'utente):

  • Dati trattati: Viene generato e trasmesso un identificatore univoco anonimo del dispositivo (Device Push Token / Player ID) e informazioni tecniche essenziali sull'ambiente operativo (versione iOS, modello dispositivo).
  • Finalità: Recapito delle sole notifiche push informative relative alle novità normative.
  • Revoca: L'utente può disattivare in qualsiasi momento la ricezione delle notifiche push tramite il toggle dedicato all'interno dell'app oppure dalle Impostazioni di iOS (Notifiche > NIS2 Monitor).

B. Permesso Calendario (EventKit)

L'app offre la funzionalità facoltativa di esportazione dei termini e delle scadenze normative NIS2 nell'app Calendario di sistema.

  • Dati trattati: L'accesso è limitato esclusivamente alla scrittura dei singoli eventi promemoria approvati dall'utente.
  • Garanzia: Nessun evento esistente, dato personale o voce preesistente nel calendario dell'utente viene letto, memorizzato o trasmesso a server remoti.

C. Assistente Normativo AI & PrivacySanitizer (Google Gemini API)

L'applicazione integra un assistente virtuale per la consultazione della documentazione NIS2, alimentato tramite API Google Gemini.

  • Sanitizzazione On-Device Preventiva: Prima dell'invio di qualsiasi query testuale ai server AI, il motore nativo PrivacySanitizer dell'app esegue una scansione e offuscamento locale automatico di indirizzi IP, email, domini aziendali e codici fiscali, garantendo che nessun dato identificativo dell'utente o della sua organizzazione venga accidentalmente trasmesso.
  • Sessioni Effimere: Le chiamate API sono eseguite tramite configurazione di rete effimera (URLSessionConfiguration.ephemeral), impedendo la memorizzazione di cookie o cache delle interrogazioni.
  • Chiavi API Utente: Qualora l'utente configuri una propria chiave API personale, questa viene custodita con crittografia hardware nel portachiavi sicuro di Apple (Keychain) e non viene mai condivisa né con il Titolare né con terzi.

4. Base Giuridica del Trattamento (GDPR)

Il trattamento dei dati per le finalità descritte si fonda su:

  • Consenso dell'Interessato (Art. 6, par. 1, lett. a del GDPR): per l'attivazione delle notifiche push e l'accesso al calendario.
  • Legittimo Interesse del Titolare (Art. 6, par. 1, lett. f del GDPR): limitatamente al corretto funzionamento tecnico dell'infrastruttura di erogazione dei feed informativi (status.json via GitHub Pages CDN).

5. Destinatari e Trasferimento dei Dati

I dati tecnici minimi necessari per l'erogazione del servizio possono essere elaborati dai seguenti fornitori di servizi in qualità di responsabili del trattamento:

  • OneSignal Inc.: gestione e recapito dei token di notifica push (Privacy Policy OneSignal).
  • Google LLC: elaborazione delle risposte dell'assistente virtuale Gemini (Privacy Policy Google).
  • GitHub Inc. (Microsoft): hosting del file di stato pubblico e del portale web statico.

Non viene effettuata alcuna cessione, vendita o locazione di dati personali a terzi per scopi promozionali o di marketing.

6. Diritti dell'Utente (Artt. 15-22 GDPR)

In conformità al Regolamento UE 2016/679 (GDPR), ciascun utente ha il diritto di:

  • Verificare se siano trattati dati personali che lo riguardano e richiederne l'accesso.
  • Revocare in qualsiasi momento il consenso precedentemente accordato (disattivazione notifiche).
  • Cancellare completamente tutti i dati memorizzati on-device (preferiti, cronologia chat, impostazioni) semplicemente eliminando l'applicazione dal dispositivo iOS.
  • Proporre reclamo all'Autorità Garante per la Protezione dei Dati Personali (garanteprivacy.it) in caso di presunta violazione.

7. Modifiche a questa Informativa

La presente informativa potrà subire aggiornamenti per riflettere innovazioni funzionali dell'applicazione o requisiti normativi sopravvenuti. Qualsiasi variazione sostanziale verrà resa nota attraverso il portale web e, ove opportuno, tramite notifica dell'applicazione.
